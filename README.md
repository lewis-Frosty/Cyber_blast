# Cyber Blast

A neon-arcade block-placement puzzle for mobile. Drag polyomino pieces
onto an 8×8 grid to clear rows and columns — but each block carries a
color, and a clear can chain-react through same-colored neighbors,
cascading across the board for escalating combo multipliers.

Colour Cascade is the differentiator: same input model as familiar
block-puzzle games (drag, place, no rotation, zero tutorial needed),
but with a real skill ceiling — players plan color clusters ahead of
clears instead of just fitting shapes.

Neon synthwave art direction. Weekly leagues, a daily challenge with a
shareable result card, and a limited-moves challenge mode that rewards
planning over speed.

Built end-to-end with Claude Code, on a Phaser/TypeScript stack chosen
specifically for AI-assisted iteration — pure, engine-free core logic
doubles as the server-side anti-cheat verifier.

Currently in Phase 1 (core loop prototype). Not yet released.
